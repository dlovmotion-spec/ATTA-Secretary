# ATTA Productions — Personal Secretary

Автономный Android-секретарь с голосовым созданием напоминаний.

## Как пользоваться
1. Нажмите «СКАЗАТЬ ЗАДАЧУ».
2. Скажите: «Завтра в 10 позвонить Сергею» или «Через 30 минут проверить заказ».
3. Приложение само распознает дату/время, сохранит задачу и поставит системное уведомление.
4. Если время не было сказано, секретарь голосом спросит «Когда напомнить?» — ответьте голосом, например «завтра в десять».

## Поддерживаемые фразы
- сегодня / завтра / послезавтра
- через N минут / часов / дней
- в 10 / в 10:30
- утром / днем / вечером / ночью
- часть украинских эквивалентов: сьогодні, післязавтра, вранці, увечері и др.

## Сборка APK
Откройте папку проекта в Android Studio, дождитесь Gradle Sync и выберите Build → Build APK(s).

Данные хранятся локально на телефоне. Сервер и учетная запись не требуются.
